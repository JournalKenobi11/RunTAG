# Dreeve Running Analytics Guidelines

## Storage & Output Directories

All running analytics, workout reports, charts, and plots generated by agents must be saved strictly to the user's dedicated project directories, never solely inside temporary/session-specific brain artifact folders:

1. **Markdown Workout Analyses & Reports:**
   - Directory: `reports/`
   - Naming convention: `workout_analysis_YYYYMMDD.md`

2. **Generated Plots, Charts & Visualizations:**
   - Directory: `output/`
   - Naming convention: `<descriptive_name>.png` / `<descriptive_name>.jpg`

3. **Analysis Scripts & Utilities:**
   - Keep reusable scripts inside `` or `scripts/`.
